mergerfs-webui service

Set up a systemd system service at /etc/systemd/system/mergerfs-webui.service. By default, the root-run server atomically copies its running version over /usr/local/bin/mergerfs-webui and configures the service to use it. Alternatively, use the currently running executable without copying it, provided its path and all parent directories are root-controlled. Choose the port the service will listen on; it defaults to this server's port. If you change it, open the new address after setup and keep this tab open until any generated password is saved. An existing --password-file is reused. Otherwise, choose whether to require a password before installing; no manual root commands are needed.

Browser writes must come from this application's origin; cross-site and same-site-but-cross-origin requests are rejected. API request bodies must use Content-Type: application/json; empty commands need no content type. HTTP and HTTPS browser origins are supported, but a reverse proxy must preserve the browser's Host header, including any non-default port. Forwarded headers do not authorize an origin. These checks do not replace password authentication or restrict non-browser clients.

Stop this web UI service?

Stopping the mergerfs-webui systemd service at disconnects Setup if this web UI is running as that service. Its unit remains installed, and its automatic-start setting is unchanged. The executable, sign-in password, mergerfs mounts, and configuration remain untouched.

If this page disconnects, manually start the service to use Setup again. An enabled service may start automatically at the next boot. Stopping the service does not remove it.

Remove automatic startup for this web UI?

This disables automatic startup and removes only the mergerfs-webui systemd service at . It does not delete the web UI executable, your sign-in password, mergerfs mounts, or mergerfs configuration.

If this web UI is running as that service, it will turn off after confirming. This page will show the result, but Setup will not work again until you manually start mergerfs-webui. To set up automatic startup again, first start the app manually and return to Setup.

Web UI service removed

Automatic startup is off. The mergerfs-webui systemd service at was removed. This web UI is shutting down now.

The web UI executable, sign-in password, mergerfs mounts, and mergerfs configuration are still in place. You can leave this tab open, but its controls are offline. To use Setup or set up automatic startup again, manually start mergerfs-webui and reopen this page.
